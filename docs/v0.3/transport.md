# Structured-output transport for v0.3

The canonical trust documents are JSON-LD. Some model structured-output adapters reject property names beginning with `@`, so v0.3 keeps the v0.1 and v0.2 approach unchanged: a generated transport representation with provider-safe aliases.

## Alias mapping

| Transport property | Canonical JSON-LD property |
|---|---|
| `jsonldContext` | `@context` |
| `jsonldContext.vocab` | `@context.@vocab` |
| `jsonldType` | `@type` |

Nothing else differs. `id` and `type` inside a document are ordinary property names whose *values* are `@id` and `@type`, so every entity keeps its identifier and type in both forms.

## Source of truth

The canonical schemas are authoritative. Transport schemas are generated by `scripts/build-transport-schema.mjs`, which now generates all seven pairs across v0.1, v0.2 and v0.3.

```bash
npm run build:transport-schema
```

The check fails if any checked-in transport schema is stale, if any property beginning with `@` survives into a transport schema or example, or if two documents in the same `defsFamily` disagree about a shared definition.

## Shared definitions across versions

A single-file schema cannot use a cross-file `$ref` and stay usable as a structured-output schema, so each document carries its own copy of the definitions it shares. In v0.3 the parity check groups by `defsFamily` rather than by version, so the four trust documents are compared against the v0.2 career profile as well as against each other. `validity`, `provenance`, `disclosure`, `verification` and the rest are one definition with six copies, not six definitions.

## Conversion

`scripts/convert-profile.mjs` and `src/v0.3/transport.ts` implement the same lossless mapping. The converter is document-agnostic and works for every document in every version.

```bash
node scripts/convert-profile.mjs --to-transport referral.jsonld referral.transport.json
node scripts/convert-profile.mjs --to-canonical referral.transport.json referral.jsonld
```

`scripts/validate_v0_3.py` regenerates each transport example from its canonical form, fails if the checked-in file differs, and round-trips the transport form back to canonical to prove the conversion loses nothing.

## Storage rule

Unchanged: the transport form is an ingestion and generation boundary only. Persist and exchange the canonical JSON-LD representation.
